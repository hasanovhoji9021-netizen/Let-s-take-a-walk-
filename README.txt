Burgundy card

How to open: double-click index.html (opens in a browser).
To send it to her, upload the whole folder to any hosting
(GitHub Pages, Netlify, Cloudflare Pages) and send her the link.

Files:
  index.html      - the card pages
  css/style.css   - styling and animations
  js/script.js    - buttons, place choice, sending to WhatsApp
  img/favicon.svg - tab icon

The WhatsApp number is set in js/script.js, line PHONE
(format without plus: 996553787767).
Fonts load from Google Fonts, so internet is required.
